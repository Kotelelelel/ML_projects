# ML_projects
Welcome! This repository serves as a collection of my personal machine learning projects, experiments, and code snippets. Each folder contains its own self-contained code and documentation.

## Projects Overview

- **[House_prices](https://github.com/Kotelelelel/ML_projects/tree/main/House_Prices)**
  * **Goal:** Prediction of house prices based on a dataset.
  * **Tech:** Python, Scikit-Learn, Pandas, Matplotlib, Seaborn.
  * **Score:** 0.13792 RMSE.

- **[Predicting_Electric_Vehicle_Purchases](https://github.com/Kotelelelel/ML_projects/tree/main/Predicting_Electric_Vehicle_Purchases)**
  * **Goal:** Prediction of customer willingness to buy EVs.
  * **Tech:** Python, Scikit-Learn, Pandas, Matplotlib, LightGBM.
  * **Score:** ROC-AUC score of 0.94189.
